# Asset sources

The profile uses locally stored SVG icon badges. Each badge includes a visible technology name and an accessible alternative in the README.

- Brand silhouettes: [Simple Icons](https://simpleicons.org/), version 16.36.0, CC0; see [license](./licenses/simple-icons-CC0.md).
- AI brand silhouettes: [Lobe Icons](https://github.com/lobehub/lobe-icons), version 1.102.0, MIT; see [license](./licenses/lobe-icons-MIT.txt).
- Additional multilayer logos: [SVG Logos](https://github.com/gilbarbara/logos), through `@iconify-json/logos` 1.2.19, CC0.
- Zustand and Kubeflow logos: [Devicon](https://github.com/devicons/devicon), through `@iconify-json/devicon` 1.2.77, MIT; see [license](./licenses/devicon-MIT.txt).
- The llama.cpp icon: [official llama.cpp media](https://github.com/ggml-org/llama.cpp/blob/master/media/llama1-icon-transparent.svg); see [license](./licenses/llama-cpp-MIT.txt).
- Method and infrastructure pictograms: [Lucide](https://lucide.dev/), version 1.69.0, ISC; see [license](./licenses/lucide-ISC.txt). These are semantic pictograms, rather than invented brand logos, for concepts such as LoRA, quantization and retrieval.
- Wordmark and badge lettering: [Switzer by Indian Type Foundry](https://www.fontshare.com/fonts/switzer). Lettering is exported as vector outlines. Font software is not distributed.

The [icon manifest](./stack/manifest.json) records the source family and source filename for every entry. Monochrome brand silhouettes share the profile ink color. Multilayer assets preserve their internal color distinctions.
